# DecodeAll

DecodeAll, çeşitli veri türlerini (örneğin, Base64, URL, JSON) kolayca çözümleyebilen ve dönüştürebilen bir ASP.NET Core MVC uygulamasıdır. Kullanıcı dostu arayüzü sayesinde, geliştiriciler ve teknik kullanıcılar için pratik bir araç sunar.

## Özellikler

- **Base64 Çözümleme:** Base64 kodlanmış verileri metne dönüştürme.
- **URL Çözümleme:** URL kodlamasını çözerek okunabilir metin elde etme.
- **JSON Formatlama:** JSON verilerini okunabilir ve düzenli bir yapıya kavuşturma.
- **Kolay Kullanım:** Basit ve sezgisel arayüz ile hızlı işlem yapma.

## Kurulum

### Gereksinimler

- [.NET 8 SDK](https://dotnet.microsoft.com/en-us/download/dotnet/8.0)
- Visual Studio 2022 veya üzeri (veya uygun bir IDE)

### Adımlar

1. **Depoyu Klonlayın:**

   ```bash
   git clone https://github.com/erdokrmn/DecodeAll.git
   cd DecodeAll
   ```

2. **Projeyi Açın:**

   Visual Studio veya tercih ettiğiniz IDE ile `DecodeAll.sln` dosyasını açın.

3. **Bağımlılıkları Yükleyin:**

   Gerekli NuGet paketlerini yükleyin.

4. **Uygulamayı Çalıştırın:**

   Projeyi derleyin ve çalıştırın. Varsayılan olarak `https://localhost:5001` adresinde hizmet verecektir.

## Kullanım

1. **Ana Sayfa:** Uygulama açıldığında ana sayfa görüntülenir.
2. **Veri Girişi:** Çözümlemek istediğiniz veriyi ilgili alana girin.
3. **İşlem Seçimi:** Uygulamak istediğiniz çözümleme türünü seçin.
4. **Sonuç:** İşlem sonucunda elde edilen veri ekranda görüntülenir.
